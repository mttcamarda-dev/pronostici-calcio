Opzione 1: API-Football (Consigliata)

  1. Vai su RapidAPI.com e crea un account gratuito
  2. Cerca "API-Football" e sottoscrivi il piano FREE (100 richieste/giorno)
  3. Copia la tua X-RapidAPI-Key
  4. Apri questo file HTML e inserisci la chiave (cerca API_KEY)
  5. Assicurati che DATA_SOURCE: 'rapidapi'

✅ Include: Tutte le competizioni mondiali (Serie A, Premier League, Champions, Europa League, etc.)

Opzione 2: Backend Locale (Solo Champions/Europa)

  1. Installa Python e dipendenze: pip install -r requirements.txt
  2. Avvia il backend: python backend_scraper.py
  3. Apri questo file HTML e imposta DATA_SOURCE: 'local'
  4. Ricarica la pagina

⚠️ Include solo: Champions League ed Europa League

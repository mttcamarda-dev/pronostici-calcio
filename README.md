# ⚽ Football Matches Website

A simple website that shows today's football matches.

## For Complete Beginners

This is your first website! Here's what you have:

### Files in this project:
- **index.html** - This is your website (the only file you need!)

### How to view your website:

1. **On your computer:**
   - Find the `index.html` file
   - Double-click it
   - It will open in your web browser!

2. **That's it!** Your website is now showing in your browser.

## What does the website show?

Right now, it shows 5 fake football matches:
- Manchester United vs Liverpool
- Real Madrid vs Barcelona
- Bayern Munich vs Borussia Dortmund
- Juventus vs AC Milan
- PSG vs Marseille

## What's inside the code?

The `index.html` file has three parts:

1. **HTML** - The structure (like the skeleton)
   - Creates the page layout
   - Adds headings and containers

2. **CSS** - The styling (like the clothes)
   - Makes it look pretty with colors
   - Adds spacing and fonts

3. **JavaScript** - The behavior (like the brain)
   - Creates the match data
   - Displays the matches on the page
